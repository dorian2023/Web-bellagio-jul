1. Resumen Ejecutivo (Para la Dirección)

La App Web de Ventas Bellagio es una herramienta de grado empresarial desarrollada para digitalizar, agilizar y controlar las ventas diarias de los asesores comerciales en todos los showrooms de Muebles Bellagio en Caracas.

Propósito Central: Permitir que los vendedores tengan todo el catálogo, disponibilidad de stock, personalización de telas, cálculo automático de presupuestos y creación formal de pedidos en sus teléfonos o tablets, eliminando errores de cotización manual y órdenes en papel.

📱 Catálogo & Lista de Precios

Búsqueda en vivo con filtros por ambiente, tipo de madera, tela y origen (Nacional o Importado).

🧾 Generador de Pedidos & Presupuestos

Creación instantánea de órdenes formales con desglose de medidas, abonos, métodos de pago y notas de taller.

🔍 Lector de Códigos QR Físicos

El asesor escanea con la cámara la etiqueta del mueble en la tienda y abre su ficha técnica en 1 segundo.

🏭 Seguimiento de Producción (CRM)

Trazabilidad en tiempo real del estado del mueble: En Taller, En Tapicería, Listo para Entrega y Despachado.

2. Arquitectura & Stack Tecnológico (Para el Ingeniero)

El sistema está estructurado bajo una arquitectura moderna Serverless Jamstack, garantizando alta velocidad de carga, escalabilidad automática y cero costo de mantenimiento de servidores físicos.

Componente Tecnología Detalle y Justificación Técnica
Frontend React 19 + TypeScript 5.9 SPA reactiva con tipado estricto al 100%, evitando errores de tipo en tiempo de ejecución.
Bundler & Build Vite 7.3 Compilación optimizada con división de código modular (Code Splitting) en 1.4 segundos.
Estilos & UI TailwindCSS 3.4 + Lucide Diseño ergonómico, ligero y totalmente responsivo (móvil, tablet y escritorio).
Base de Datos PostgreSQL 15 (Supabase Cloud) Base de datos relacional con claves foráneas, índices de búsqueda y migraciones SQL versionadas.
Seguridad Row Level Security (RLS) Políticas a nivel de fila en la base de datos que controlan accesos según el rol de cada usuario.
Alojamiento & CDN Vercel Edge Network Despliegue continuo automatizado (CI/CD) conectado a la rama main de GitHub.

3. Seguridad & Matriz de Roles

La aplicación implementa el modelo de seguridad Zero-Trust con autenticación JWT y control de acceso basado en roles (RBAC):

Rol de Usuario Alcance de Permisos en el Sistema
Super Administrador
(Tu Jefe / Dirección)		 • Control total de todas las sedes y vendedores.
• Creación, edición y anulación de pedidos globales.
• Gestión de precios, comisiones, costos y márgenes.
• Creación y revocación de cuentas de vendedores y almacén.
• Acceso a métricas de facturación y exportación de reportes.
Vendedor / Asesor Comercial • Creación de presupuestos y pedidos en su tienda asignada.
• Consulta de catálogo, medidas y stock disponible.
• Seguimiento del estado de sus propios clientes.
• Restricción estricta: NO puede ver costos internos ni pedidos de otros asesores.
Almacén / Despacho • Visualización de órdenes listas para entrega.
• Actualización de estados de entrega y comprobantes de despacho.

4. Plan de Traspaso de Propiedad a la Empresa (Continuidad Garantizada)

Garantía para la Dirección: El objetivo de este procedimiento es transferir la titularidad y administración principal de todas las cuentas a nombre de la empresa, de modo que la dirección tenga el 100% del control del código fuente, la base de datos y el hosting, garantizando la continuidad del negocio sin depender de una sola persona.
  • 1
    Traspaso del Código Fuente (GitHub):
    Se crea una Organización corporativa en GitHub (ej. Muebles-Bellagio-Oficial) donde el jefe es el Owner (Dueño absoluto). El repositorio APP_VENTA se transfiere a esa organización. El desarrollador queda como colaborador técnico.
  • 2
    Traspaso del Hosting y Despliegues (Vercel):
    Se transfiere el proyecto app-venta-4myb al equipo corporativo de Vercel bajo el correo de la empresa. La dirección obtiene acceso a métricas, dominios y variables de entorno.
  • 3
    Traspaso de la Base de Datos & Clientes (Supabase):
    Se transfiere el proyecto de PostgreSQL a la organización corporativa en Supabase. Se activa la política de copias de seguridad automáticas diarias (Backups) descargables.
  • 4
    Gestor de Contraseñas Corporativo:
    Todas las credenciales maestras y llaves de API se almacenan en una bóveda segura (Bitwarden / 1Password) bajo el correo oficial de la empresa.
